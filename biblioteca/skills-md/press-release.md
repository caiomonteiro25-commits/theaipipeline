# Press Release — Nota de Imprensa Profissional

## Input necessário
```
ASSUNTO: [o que está sendo comunicado — lançamento / evento / parceria / prêmio]
EMPRESA/ARTISTA: [quem está comunicando]
DATA: [quando acontece ou aconteceu]
CITAÇÃO: [frase do porta-voz para o release]
```

## Workflow
### ETAPA 1 — Briefing
Definir o objetivo central e o resultado esperado antes de começar a produzir.

### ETAPA 2 — Estrutura
Montar o esqueleto do documento, roteiro ou mensagem antes de preencher o conteúdo.

### ETAPA 3 — Desenvolvimento
Preencher cada parte com conteúdo real, específico e alinhado ao objetivo.

### ETAPA 4 — Revisão de Impacto
A peça cumpre seu objetivo? O leitor/espectador vai fazer o que precisa fazer?

### ETAPA 5 — Entrega
Formato final pronto para uso imediato, sem necessidade de edição adicional.

## Output
```
[RELEASE COMPLETO] — pronto para enviar para imprensa
[VERSÃO CURTA] — 150 palavras para redes sociais
[LISTA DE VEÍCULOS] — sugestão de onde enviar
```
## Regras
Lead do release deve responder: quem, o quê, quando, onde, por quê — em 2 frases.
