# Email Pro — Email Profissional para Qualquer Situação

## Input necessário
```
TIPO: [cobrança / proposta / follow-up / reclamação / agradecimento / boas-vindas]
TOM: [formal / descontraído / urgente / empático]
DESTINATÁRIO: [perfil — cliente / parceiro / fornecedor / equipe]
CONTEXTO: [o que aconteceu antes desse email]
```

## Workflow
### ETAPA 1 — Tipo e Tom
Definir: qual o objetivo do email (informar / pedir / agradecer / cobrar) e qual o tom adequado ao destinatário.

### ETAPA 2 — Estrutura
Assunto: claro e específico — nunca genérico. Abertura: contextualizar em 1 frase. Corpo: 1-3 parágrafos curtos. Fechamento: CTA claro.
