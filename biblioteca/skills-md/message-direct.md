# Message Direct — Mensagem Direta para Qualquer Canal

## Input necessário
```
CANAL: [WhatsApp / Telegram / Instagram DM / LinkedIn]
OBJETIVO: [pedir / informar / vender / confirmar / reagendar]
TOM: [próximo / profissional / urgente / casual]
CONTEXTO: [relação com o destinatário]
```

## Workflow
### ETAPA 1 — Objetivo em 1 Frase
Antes de escrever: o que precisa que a pessoa faça ou saiba após ler?

### ETAPA 2 — Tamanho
Máximo 3-4 linhas por mensagem. Se precisar de mais: dividir em tópicos numerados ou enviar email.
