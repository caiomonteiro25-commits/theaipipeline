# Content Calendar — Calendário de Conteúdo Multi-Plataforma

## Input necessário
```
PLATAFORMAS: [quais redes]
FREQUÊNCIA: [posts por semana por plataforma]
NICHO/ÁREA: [sobre o que é o perfil]
MÊS DE REFERÊNCIA: [para sazonalidade]
OBJETIVO: [seguidores / leads / vendas / awareness]
```

## Workflow
### ETAPA 1 — Estratégia
Definir pilares de conteúdo: 4-5 temas fixos que a marca fala. Proporção entre cada pilar.

### ETAPA 2 — Estrutura
Grade semanal: distribuir os pilares pelos dias. Variar formatos: carrossel, vídeo, estático, stories.

### ETAPA 3 — Criação
Escrever o conteúdo com base na estrutura definida. Foco no objetivo principal de cada peça.

### ETAPA 4 — Revisão de Tom
Verificar que o tom está alinhado com a voz da marca. Ajustar o que soar genérico ou fora do padrão.

### ETAPA 5 — Entrega
Grade em tabela: Data | Tema | Formato | Plataforma | Texto | CTA.

## Output
```
[GRADE DO MÊS] — tabela completa com todos os dias
[TEMAS POR SEMANA] — pilares distribuídos
[DATAS ESPECIAIS] — oportunidades de pauta do mês
```
## Regras
Nunca planejar post a post — calendário mensal economiza 80% do tempo de criação.
