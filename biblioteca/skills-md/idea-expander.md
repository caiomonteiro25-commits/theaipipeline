# Idea Expander — Expansor de Ideias com Execução Real

## Input necessário
```
IDEIA ORIGINAL: [descrever em 1-3 frases]
ÁREA: [negócio / produto / conteúdo / evento / sistema]
CONTEXTO: [mercado, recursos disponíveis, restrições]
OBJETIVO: [o que a ideia precisa alcançar]
```

## Workflow
### ETAPA 1 — Briefing
Definir o objetivo central e o resultado esperado antes de começar a produzir.

### ETAPA 2 — Estrutura
Montar o esqueleto do documento, roteiro ou mensagem antes de preencher o conteúdo.

### ETAPA 3 — Desenvolvimento
Preencher cada parte com conteúdo real, específico e alinhado ao objetivo.

### ETAPA 4 — Revisão de Impacto
A peça cumpre seu objetivo? O leitor/espectador vai fazer o que precisa fazer?

### ETAPA 5 — Entrega
Formato final pronto para uso imediato, sem necessidade de edição adicional.

## Output
```
[IDEIA CENTRAL REFINADA] — versão melhorada da ideia original
[10 DERIVAÇÕES] — expansões com caminho de execução
[PRÓXIMOS PASSOS] — ação concreta para começar esta semana
```
## Regras
Derivação sem caminho de execução é só brainstorming — cada ideia precisa ter próximo passo concreto.
