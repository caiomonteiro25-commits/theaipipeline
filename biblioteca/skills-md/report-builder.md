# Report Builder — Relatório Executivo

## Input necessário
```
PERÍODO: [referência do relatório — mês / semana / projeto]
AUDIÊNCIA: [quem vai ler — cliente / sócio / equipe / diretoria]
DADOS DISPONÍVEIS: [o que tem para reportar]
OBJETIVO: [informar / justificar / decidir / apresentar resultado]
```

## Workflow
### ETAPA 1 — Headline
Definir o resultado mais importante em 1 número ou frase — isso é o headline do relatório.

### ETAPA 2 — Dados
Apresentar métricas em ordem: resultado de negócio primeiro / métricas de canal depois.

### ETAPA 3 — Análise
Interpretar os dados: o que eles significam para o negócio, não só o que são.

### ETAPA 4 — Revisão
Verificar que o documento está completo e que qualquer pessoa da equipe consegue executar sem pedir explicação.

### ETAPA 5 — Distribuição
Definir onde o documento vive (Notion, Drive, email) e quem precisa ter acesso.

## Output
```
[RELATÓRIO COMPLETO] — com análise e dados
[RESUMO EXECUTIVO] — 3-5 pontos principais
[PRÓXIMAS AÇÕES] — o que fazer com base nos dados
```
## Regras
Relatório sem interpretação é planilha. O valor está na análise, não nos números brutos.
