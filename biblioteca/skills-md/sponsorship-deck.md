# Sponsorship Deck — Proposta de Patrocínio Profissional

## Input necessário
```
EVENTO/PROJETO: [o que está sendo patrocinado]
ALCANCE: [público estimado — número e perfil]
COTAS: [valores e nomes das cotas]
BENEFÍCIOS POR COTA: [o que cada patrocinador recebe]
```

## Workflow
### ETAPA 1 — Briefing
Definir o objetivo central e o resultado esperado antes de começar a produzir.

### ETAPA 2 — Estrutura
Montar o esqueleto do documento, roteiro ou mensagem antes de preencher o conteúdo.

### ETAPA 3 — Desenvolvimento
Preencher cada parte com conteúdo real, específico e alinhado ao objetivo.

### ETAPA 4 — Revisão de Impacto
A peça cumpre seu objetivo? O leitor/espectador vai fazer o que precisa fazer?

### ETAPA 5 — Entrega
Formato final pronto para uso imediato, sem necessidade de edição adicional.

## Output
```
[PROPOSTA COMPLETA] — cotas e benefícios formatados
[EMAIL DE ABORDAGEM] — texto para enviar junto
[ARGUMENTOS DE ROI] — como justificar o investimento para cada perfil de patrocinador
```
## Regras
Argumento de ROI é obrigatório — patrocinador precisa justificar internamente o investimento.
