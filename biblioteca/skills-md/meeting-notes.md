# Meeting Notes — Ata de Reunião Estruturada

## Input necessário
```
ANOTAÇÕES BRUTAS: [colar o que foi anotado durante a reunião]
PARTICIPANTES: [quem estava na reunião]
DATA: [quando foi]
CONTEXTO: [sobre o que foi a reunião]
```

## Workflow
### ETAPA 1 — Estruturação
Organizar em: contexto / decisões tomadas / próximos passos / pendências.

### ETAPA 2 — Decisões
Listar decisões com: o que foi decidido / quem decidiu / quais foram as alternativas descartadas.

### ETAPA 3 — Próximos Passos
Lista de próximos passos: tarefa + responsável + prazo — sem ambiguidade.

### ETAPA 4 — Revisão
Verificar que o documento está completo e que qualquer pessoa da equipe consegue executar sem pedir explicação.

### ETAPA 5 — Distribuição
Definir onde o documento vive (Notion, Drive, email) e quem precisa ter acesso.

## Output
```
[ATA ESTRUTURADA] — pronta para enviar por email
[PRÓXIMOS PASSOS] — lista com responsável e prazo
[DECISÕES TOMADAS] — registro formal
```
## Regras
Enviar ata em até 24h após a reunião — depois disso, as memórias divergem.
