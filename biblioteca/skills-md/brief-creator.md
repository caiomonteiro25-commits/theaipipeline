# Brief Creator — Criação de Brief Completo

## Input necessário
```
DEMANDA: [o que precisa ser feito]
DESTINATÁRIO: [equipe interna / fornecedor / agência]
PRAZO: [data de entrega]
ORÇAMENTO: [se aplicável]
```

## Workflow
### ETAPA 1 — Contexto
Definir o contexto: por que essa demanda existe, o que acontece se não for bem feita.

### ETAPA 2 — Objetivo e Entregável
Definir: o que deve ser entregue, em qual formato, com quais requisitos obrigatórios.

### ETAPA 3 — Referências
Exemplos e referências visuais ou textuais que orientam a execução.

### ETAPA 4 — Revisão
Verificar que o documento está completo e que qualquer pessoa da equipe consegue executar sem pedir explicação.

### ETAPA 5 — Distribuição
Definir onde o documento vive (Notion, Drive, email) e quem precisa ter acesso.

## Output
```
[BRIEF COMPLETO] — todos os campos preenchidos
[PERGUNTAS OBRIGATÓRIAS] — o que ainda precisa de resposta
[CRITÉRIO DE APROVAÇÃO] — como saber se o resultado está correto
```
## Regras
Brief incompleto gera entrega errada — melhor perguntar antes do que refazer depois.
