# Prompt Engineer — Engenharia de Prompts para IA

## Input necessário
```
FERRAMENTA: [ChatGPT / Claude / Midjourney / Suno / Kling / outro]
OBJETIVO: [o que precisa gerar]
INSTRUÇÃO ORIGINAL: [o que o usuário pediu de forma vaga]
TOM E ESTILO: [especificações de resultado]
```

## Workflow
### ETAPA 1 — Briefing
Definir o objetivo central e o resultado esperado antes de começar a produzir.

### ETAPA 2 — Estrutura
Montar o esqueleto do documento, roteiro ou mensagem antes de preencher o conteúdo.

### ETAPA 3 — Desenvolvimento
Preencher cada parte com conteúdo real, específico e alinhado ao objetivo.

### ETAPA 4 — Revisão de Impacto
A peça cumpre seu objetivo? O leitor/espectador vai fazer o que precisa fazer?

### ETAPA 5 — Entrega
Formato final pronto para uso imediato, sem necessidade de edição adicional.

## Output
```
[PROMPT OTIMIZADO] — pronto para colar na ferramenta
[3 VARIAÇÕES] — diferentes abordagens para o mesmo objetivo
[INSTRUÇÕES DE USO] — como ajustar se o resultado não for o esperado
```
## Regras
Prompt vago = resultado genérico. Especificidade é o que separa geração medíocre de geração profissional.
