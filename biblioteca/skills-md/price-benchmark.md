# Price Benchmark — Referência de Preços de Mercado

## Input necessário
```
O QUE PESQUISAR: [produto / serviço / profissional / fornecedor]
MERCADO: [cidade / estado / nacional / internacional]
FAIXA DE QUALIDADE: [básico / intermediário / premium]
OBJETIVO: [precificar / negociar / apresentar para cliente]
```

## Workflow
### ETAPA 1 — Coleta de Referências
Mínimo de 5 referências de preço por categoria: sites, orçamentos diretos, comparadores, grupos de referência.

### ETAPA 2 — Segmentação por Tier
Básico (menor preço) / Intermediário (preço médio) / Premium (maior preço) — e o que justifica cada tier.

### ETAPA 3 — Análise de Variáveis
O que faz o preço variar: volume, prazo, reputação, localização, diferenciais incluídos.

### ETAPA 4 — Posicionamento
Onde o produto/serviço analisado se encaixa nessa escala e por quê.

### ETAPA 5 — Recomendação
Faixa de preço sugerida com justificativa de mercado.

## Output
```
[TABELA DE REFERÊNCIAS] — 5+ preços coletados com fonte
[ANÁLISE POR TIER] — básico / médio / premium com critérios
[VARIÁVEIS] — o que faz o preço subir ou cair
[RECOMENDAÇÃO] — faixa de preço sugerida e posicionamento
```
