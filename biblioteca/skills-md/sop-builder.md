# SOP Builder — Procedimento Operacional Padrão

## Input necessário
```
PROCESSO: [o que precisa documentar]
QUEM EXECUTA: [função responsável]
FREQUÊNCIA: [quando é executado]
FERRAMENTAS USADAS: [o que a pessoa usa para executar]
```

## Workflow
### ETAPA 1 — Mapeamento
Mapear o processo do início ao fim antes de documentar. Quem faz o quê, em que ordem.

### ETAPA 2 — Passo a Passo
Descrever cada etapa com início, ação e critério de conclusão. Com capturas de tela se necessário.

### ETAPA 3 — Exceções e Erros
Documentar o que fazer quando algo sai do esperado. Casos de exceção e quem acionar.

### ETAPA 4 — Revisão
Verificar que o documento está completo e que qualquer pessoa da equipe consegue executar sem pedir explicação.

### ETAPA 5 — Distribuição
Definir onde o documento vive (Notion, Drive, email) e quem precisa ter acesso.

## Output
```
[PROCEDIMENTO COMPLETO] — passo a passo documentado
[CHECKLIST] — versão condensada para uso diário
[RESPONSÁVEIS] — quem executa e quem valida
```
## Regras
SOP deve ser testado por alguém que nunca fez o processo antes de ser aprovado.
