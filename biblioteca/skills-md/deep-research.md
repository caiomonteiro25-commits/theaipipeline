# Deep Research — Pesquisa Profunda com Síntese Executiva

## Input necessário
```
TEMA: [o que pesquisar]
PROFUNDIDADE: [visão geral / análise média / pesquisa completa]
DESTINO: [uso interno / apresentação para cliente / tomada de decisão]
PRAZO: [urgente / sem pressa]
```

## Workflow
### ETAPA 1 — Escopo
Definir o que precisa ser respondido: 3-5 perguntas centrais que a pesquisa deve responder.

### ETAPA 2 — Fontes por Tipo de Dado
- Dados de mercado: IBGE, Statista, relatórios setoriais, associações do setor
- Concorrentes: sites, LinkedIn, Google Maps, redes sociais, Reclame Aqui
- Tendências: Google Trends, Think with Google, relatórios anuais de plataformas
- Preços: pesquisa direta, plataformas de e-commerce, cotação com fornecedores

### ETAPA 3 — Estrutura da Síntese
1. Headline: resposta principal em 1-2 frases
2. Contexto: o que explica o cenário atual
3. Dados-chave: 3-5 números mais relevantes
4. Oportunidades identificadas: o que o dado sugere fazer
5. Riscos: o que o dado sugere evitar
6. Fontes: listar todas as referências usadas

### ETAPA 4 — Validação
Cruzar informações de pelo menos 2 fontes antes de afirmar qualquer dado.

### ETAPA 5 — Entrega
Formato por destino: bullets executivos (reunião) / documento (apresentação) / tabela (comparativo).

## Output
```
[HEADLINE] — resposta principal em 2 frases
[DADOS-CHAVE] — 3-5 números com fonte
[ANÁLISE] — o que os dados significam para o negócio
[OPORTUNIDADES E RISCOS] — ações sugeridas
[FONTES] — lista de referências
```
## Regras
- Nunca afirmar dado sem fonte verificável
- Dados com mais de 2 anos: sinalizar como possivelmente desatualizado
- Síntese executiva no início — detalhe no final, não ao contrário
