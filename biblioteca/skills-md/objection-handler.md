# Objection Handler — Contorno de Objeções

## Input necessário
```
PRODUTO/SERVIÇO: [o que está sendo vendido]
OBJEÇÃO RECEBIDA: [o que o cliente disse]
CONTEXTO: [em qual etapa da venda está]
```

## Workflow
### ETAPA 1 — Classificar a Objeção
Preço (caro) / Timing (agora não) / Autoridade (preciso falar com alguém) / Necessidade (não preciso) / Confiança (não te conheço).
### ETAPA 2 — Validar Antes de Responder
Nunca rebater direto. Validar: 'Entendo, faz todo sentido.' Isso baixa a defensividade.
### ETAPA 3 — Reformular
Transformar a objeção em pergunta: 'Você está dizendo que o valor está acima do orçamento atual, certo?'
### ETAPA 4 — Responder com Valor
Não defender o preço — reforçar o valor. O que o cliente perde se não fechar.
### ETAPA 5 — Reperguntar
Após responder: 'Faz sentido para você?' — checar se a objeção foi resolvida ou se há outra.

## Output
```
[SCRIPT DE CONTORNO] — resposta por tipo de objeção
[REFORMULAÇÃO] — como transformar cada objeção em pergunta
[FRASES PROIBIDAS] — o que nunca dizer em cada objeção
```
## Regras
Nunca dar desconto imediatamente — sempre explorar a objeção antes. 70% das objeções de preço são objeção de valor.
