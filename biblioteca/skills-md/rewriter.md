# Rewriter — Reescrita e Melhoria de Qualquer Texto

## Input necessário
```
TEXTO ORIGINAL: [colar o texto que precisa melhorar]
PROBLEMA: [o que está errado — confuso / longo / tom errado / mal escrito]
DESTINO: [email / post / documento / apresentação]
TOM DESEJADO: [formal / casual / persuasivo / informativo]
```

## Workflow
### ETAPA 1 — Diagnóstico
Identificar: o texto está confuso, longo, informal demais, formal demais, sem objetivo claro?

### ETAPA 2 — Intenção
Definir o que o texto precisa causar no leitor: entender / agir / confiar / comprar.
