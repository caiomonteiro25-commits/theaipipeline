# Ad Copy — Copy de Anúncio para Meta e Google Ads

## Input necessário
```
PRODUTO/SERVIÇO: [o que está sendo anunciado]
PLATAFORMA: [Meta Ads / Google Ads / ambos]
OBJETIVO: [conversão / lead / awareness / tráfego]
PÚBLICO: [perfil do público-alvo]
DIFERENCIAL: [o que torna esse produto único]
```

## Workflow
### ETAPA 1 — Estratégia
Mapear: qual a dor principal que o produto resolve. Quem está com essa dor agora.

### ETAPA 2 — Estrutura
Headline: dor ou desejo em 5 palavras. Body: benefício + prova. CTA: ação específica.

### ETAPA 3 — Criação
Escrever o conteúdo com base na estrutura definida. Foco no objetivo principal de cada peça.

### ETAPA 4 — Revisão de Tom
Verificar que o tom está alinhado com a voz da marca. Ajustar o que soar genérico ou fora do padrão.

### ETAPA 5 — Entrega
Entregar: 3 headlines + 2 versões de body + 3 opções de CTA.

## Output
```
[3 HEADLINES] — variações de abertura
[2 BODY TEXTS] — versão curta e longa
[3 CTAs] — chamadas para ação diferentes
```
## Regras
Headline decide 80% do resultado — escrever 10 headlines e escolher os 3 melhores.
