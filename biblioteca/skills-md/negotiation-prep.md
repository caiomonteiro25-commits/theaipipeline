# Negotiation Prep — Preparação Estratégica de Negociação

## Input necessário
```
O QUE NEGOCIAR: [preço / prazo / escopo / parceria / contrato]
CONTRAPARTE: [perfil de quem vai negociar]
NOSSA POSIÇÃO IDEAL: [o que queremos]
LIMITE MÍNIMO: [o mínimo aceitável]
ALTERNATIVA SE NÃO FECHAR: [BATNA — o que fazemos se não chegar acordo]
```

## Workflow
### ETAPA 1 — Definir Posições
Âncora (abertura) / Alvo (objetivo real) / Limite (o mínimo) / BATNA (alternativa fora da mesa).
### ETAPA 2 — Mapear Interesses da Contraparte
O que a contraparte realmente quer (interesses) vs o que ela está pedindo (posições).
### ETAPA 3 — Concessões Planejadas
Lista de concessões que podemos fazer — em ordem decrescente de valor para nós.
### ETAPA 4 — Ancoragem
Quem faz a primeira oferta e como — ancorar alto (se vender) ou baixo (se comprar).
### ETAPA 5 — Sinais de Fechamento
Como reconhecer que a contraparte está pronta para fechar e quando pressionar.

## Output
```
[POSIÇÕES DEFINIDAS] — âncora, alvo, limite, BATNA
[MAPA DE INTERESSES] — o que a contraparte quer de verdade
[CONCESSÕES PLANEJADAS] — o que podemos ceder e em que ordem
[SCRIPT DE ABERTURA] — como começar a negociação
```
## Regras
Nunca revelar o limite mínimo ou o BATNA durante a negociação. Silêncio após oferta é tática — não preencher.
