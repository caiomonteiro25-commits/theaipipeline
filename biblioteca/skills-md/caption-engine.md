# Caption Engine — Motor de Legendas para Redes Sociais

## Input necessário
```
PLATAFORMA: [Instagram / TikTok / LinkedIn / todos]
OBJETIVO: [engajamento / venda / awareness / educação]
NICHO: [área de conteúdo]
TOM: [da marca — formal / descontraído / inspirador / técnico]
TEMA DO POST: [sobre o que é esse conteúdo específico]
```

## Workflow
### ETAPA 1 — Estratégia
Definir: objetivo do post e emoção que precisa gerar no leitor.

### ETAPA 2 — Estrutura
Gancho (1-2 linhas) + Corpo (valor ou história) + CTA (1 ação clara).

### ETAPA 3 — Criação
Escrever o conteúdo com base na estrutura definida. Foco no objetivo principal de cada peça.

### ETAPA 4 — Revisão de Tom
Verificar que o tom está alinhado com a voz da marca. Ajustar o que soar genérico ou fora do padrão.

### ETAPA 5 — Entrega
Entregar 3 variações de legenda para a mesma imagem — testar A/B se possível.

## Output
```
[3 LEGENDAS] — para o mesmo conteúdo em tons diferentes
[HASHTAGS] — sugestão por plataforma
[CTA VARIAÇÕES] — diferentes chamadas para ação
```
## Regras
CTA é obrigatório — post sem próximo passo claro desperdiça alcance.
