# Video Script — Roteiro de Vídeo Completo

## Input necessário
```
FORMATO: [talking head / reels / institucional / entrevista / tutorial]
DURAÇÃO: [segundos ou minutos]
PLATAFORMA: [YouTube / Instagram / TikTok / apresentação]
TEMA: [sobre o que é o vídeo]
TOM: [da marca]
```

## Workflow
### ETAPA 1 — Briefing
Definir o objetivo central e o resultado esperado antes de começar a produzir.

### ETAPA 2 — Estrutura
Montar o esqueleto do documento, roteiro ou mensagem antes de preencher o conteúdo.

### ETAPA 3 — Desenvolvimento
Preencher cada parte com conteúdo real, específico e alinhado ao objetivo.

### ETAPA 4 — Revisão de Impacto
A peça cumpre seu objetivo? O leitor/espectador vai fazer o que precisa fazer?

### ETAPA 5 — Entrega
Formato final pronto para uso imediato, sem necessidade de edição adicional.

## Output
```
[ROTEIRO COMPLETO] — bloco a bloco com duração e marcações
[LOCUÇÃO] — texto para ler na câmera ou gravar
[B-ROLL SUGERIDO] — imagens de apoio recomendadas
```
## Regras
Roteiro deve funcionar lido em voz alta — se travar ao ler, o telespectador também vai perder.
