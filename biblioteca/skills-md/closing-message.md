# Closing Message — Mensagem de Fechamento de Venda

## Input necessário
```
PRODUTO/SERVIÇO: [o que está sendo vendido]
SITUAÇÃO: [onde está na conversa — nunca respondeu / disse que vai pensar / pediu prazo]
CANAL: [WhatsApp / email]
PRAZO: [há urgência real?]
```

## Workflow
### ETAPA 1 — Briefing
Definir o objetivo central e o resultado esperado antes de começar a produzir.

### ETAPA 2 — Estrutura
Montar o esqueleto do documento, roteiro ou mensagem antes de preencher o conteúdo.

### ETAPA 3 — Desenvolvimento
Preencher cada parte com conteúdo real, específico e alinhado ao objetivo.

### ETAPA 4 — Revisão de Impacto
A peça cumpre seu objetivo? O leitor/espectador vai fazer o que precisa fazer?

### ETAPA 5 — Entrega
Formato final pronto para uso imediato, sem necessidade de edição adicional.

## Output
```
[MENSAGEM PRINCIPAL] — pronta para enviar
[TIMING] — quando enviar
[VARIAÇÃO MAIS DIRETA] — para caso de urgência real
```
## Regras
Urgência artificial destrói confiança — criar urgência real ou não criar urgência nenhuma.
