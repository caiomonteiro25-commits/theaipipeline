# Hook Factory — Fábrica de Ganchos de Abertura

## Input necessário
```
PLATAFORMA: [onde o conteúdo vai ao ar]
NICHO: [área de conteúdo]
OBJETIVO DO CONTEÚDO: [engajar / vender / educar / entreter]
TOM: [da marca]
```

## Workflow
### ETAPA 1 — Estratégia
Identificar: o que faz alguém parar o scroll nesse nicho. Quais padrões funcionam.

### ETAPA 2 — Estrutura
Tipos de gancho: pergunta provocadora / estatística impactante / afirmação controversa / promessa / história.

### ETAPA 3 — Criação
Escrever o conteúdo com base na estrutura definida. Foco no objetivo principal de cada peça.

### ETAPA 4 — Revisão de Tom
Verificar que o tom está alinhado com a voz da marca. Ajustar o que soar genérico ou fora do padrão.

### ETAPA 5 — Entrega
Lista de 10 ganchos prontos para usar — variados em tipo e abordagem.

## Output
```
[10 GANCHOS] — prontos para usar
[VARIAÇÕES POR TIPO] — pergunta, stat, promessa, história, provocação
[DICAS DE USO] — qual tipo funciona melhor em cada contexto
```
## Regras
Gancho = promessa implícita — o conteúdo deve cumprir o que o gancho prometeu.
