# Proposal Builder — Proposta Comercial Completa

## Input necessário
```
CLIENTE: [nome e empresa]
SERVIÇO: [o que vai ser entregue]
PRAZO: [duração do projeto]
VALOR: [preço a apresentar]
TOM: [formal / intermediário]
```

## Workflow
### ETAPA 1 — Problema do Cliente
Descrever o problema ou oportunidade que o cliente enfrenta — em palavras dele, não nossas.
### ETAPA 2 — Nossa Solução
Como resolvemos o problema. O que inclui, o que não inclui. Diferenciais.
### ETAPA 3 — Escopo e Entregáveis
Lista clara do que vai ser entregue, em qual prazo, por qual processo.
### ETAPA 4 — Investimento
Valor, forma de pagamento, o que acontece se quiser adicionar escopo.
### ETAPA 5 — Próximos Passos
O que o cliente precisa fazer para começar: assinar / pagar / agendar kick-off.

## Output
```
[PROPOSTA COMPLETA] — documento pronto para enviar
[VERSÃO RESUMIDA] — 1 página para apresentação verbal
[EMAIL DE ENVIO] — texto de acompanhamento
```
## Regras
Nunca enviar proposta sem ter falado com o cliente antes — proposta fria tem taxa de conversão baixa.
Prazo de validade: sempre colocar data de validade (7-15 dias) para criar urgência real.
