# Adobe Stock Integration — Assets Licenciados Direto nos Apps

## Acesso por App
- **Photoshop:** File → Search Adobe Stock / Libraries panel → Stock
- **Illustrator:** Window → Adobe Stock
- **InDesign:** File → Search Adobe Stock
- **Premiere:** busca no Media Browser integrada ao Stock
- **After Effects:** Libraries panel com assets de Stock

## Workflow de Uso Correto
1. Buscar com watermark → colocar como placeholder no projeto
2. Apresentar ao cliente com watermark para aprovação
3. Licenciar apenas após aprovação — o asset substitui o watermark automaticamente
4. Asset licenciado vai para a CC Library do projeto automaticamente

## Tipos de Asset e Quando Usar
```
FOTO: campanha, editorial, placeholder de maquete
VÍDEO: b-roll, background de motion, abertura de apresentação
VETOR: ícone, ilustração, elemento gráfico
ÁUDIO: trilha para vídeo, efeito sonoro, jingle de base
TEMPLATE: ponto de partida para InDesign ou After Effects
3D: modelo de produto para composição no Substance 3D
```

## Adobe Stock + Firefly (Novo 2024)
Assets gerados por Firefly agora disponíveis no catálogo:
- Buscar "AI Generated" no filtro para encontrar conteúdo Firefly
- Content Credentials incluso automaticamente em assets gerados por IA
- Uso comercial seguro — Adobe garante indemnização por uso licenciado

## Custo e Planos
- Creative Cloud All Apps: inclui créditos mensais de Stock (varia por plano)
- Imagens gratuitas: filtrar por "Free" — qualidade menor mas sem custo adicional
- Enhanced License: para uso em embalagem, produto físico ou tiragem acima de 500.000 cópias

## Regras
- NUNCA usar imagem com watermark em entrega final — é uso não licenciado
- Verificar licença: Standard vs Enhanced antes de usar em produto físico
- Assets de Stock na Library: organizar por projeto para facilitar renovação de licença
