# Competitor Intel — Inteligência Competitiva

## Input necessário
```
SETOR: [área do negócio]
CONCORRENTES: [listar 3-5 ou "identificar os principais"]
ASPECTO FOCO: [preço / comunicação / produto / atendimento / todos]
OBJETIVO: [diferenciar / precificar / posicionar / apresentar para cliente]
```

## Workflow
### ETAPA 1 — Identificação
Mapear concorrentes diretos (mesmo produto/público) e indiretos (solve o mesmo problema de forma diferente).

### ETAPA 2 — Análise por Eixo
Para cada concorrente: proposta de valor / público / preço / canais / tom de comunicação / pontos fortes / pontos fracos.

### ETAPA 3 — Coleta de Dados
Fontes: site oficial / redes sociais / Google Maps (reviews) / Reclame Aqui / LinkedIn / comparadores de preço.

### ETAPA 4 — Matriz Comparativa
Tabela: Critério | Empresa A | Empresa B | Empresa C | Nosso Negócio.

### ETAPA 5 — Insights e Oportunidades
O que nenhum concorrente está fazendo bem. Onde está o espaço de diferenciação real.

## Output
```
[MAPA DE CONCORRENTES] — quem são e o que fazem
[MATRIZ COMPARATIVA] — tabela lado a lado
[ANÁLISE DE GAPS] — o que está faltando no mercado
[OPORTUNIDADE DE POSICIONAMENTO] — onde se diferenciar
```
