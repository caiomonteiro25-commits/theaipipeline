# Event Rundown — Timeline de Evento Minuto a Minuto

## Input necessário
```
EVENTO: [nome e tipo]
DATA E HORA: [início e término]
ATRAÇÕES/ATIVIDADES: [lista do que vai acontecer]
EQUIPE: [funções presentes]
VENUE: [espaço e características]
```

## Workflow
### ETAPA 1 — Briefing
Definir o objetivo central e o resultado esperado antes de começar a produzir.

### ETAPA 2 — Estrutura
Montar o esqueleto do documento, roteiro ou mensagem antes de preencher o conteúdo.

### ETAPA 3 — Desenvolvimento
Preencher cada parte com conteúdo real, específico e alinhado ao objetivo.

### ETAPA 4 — Revisão de Impacto
A peça cumpre seu objetivo? O leitor/espectador vai fazer o que precisa fazer?

### ETAPA 5 — Entrega
Formato final pronto para uso imediato, sem necessidade de edição adicional.

## Output
```
[TIMELINE COMPLETA] — minuto a minuto com responsáveis
[PONTOS CRÍTICOS] — momentos que precisam de atenção especial
[PLANO B] — contingência para as principais situações de risco
```
## Regras
Rundown sem responsável por cada item é só uma lista — não um plano operacional.
