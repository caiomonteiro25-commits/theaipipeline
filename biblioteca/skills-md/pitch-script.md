# Pitch Script — Roteiro de Pitch Verbal

## Input necessário
```
DURAÇÃO: [2 min / 5 min / 10 min / 30 min]
FORMATO: [reunião / ligação / evento / elevador]
PRODUTO/SERVIÇO: [o que está sendo apresentado]
PÚBLICO: [perfil do interlocutor — CEO / comprador / investidor]
```

## Workflow
### ETAPA 1 — Gancho de Abertura (30s)
Frase que captura atenção imediatamente. Não começar com 'Meu nome é X e faço Y'.
### ETAPA 2 — Problema (60s)
Articular o problema do público-alvo de forma que eles se reconheçam.
### ETAPA 3 — Solução (90s)
Como resolvemos o problema. Concreto e específico — não genérico.
### ETAPA 4 — Prova (60s)
Case, número, depoimento ou demonstração que prova que funciona.
### ETAPA 5 — Fechamento (30s)
Próximo passo claro: agendar reunião / enviar proposta / fazer demonstração.

## Output
```
[SCRIPT COMPLETO] — palavra por palavra por bloco de tempo
[PONTOS-CHAVE] — se precisar improvisar
[RESPOSTAS A PERGUNTAS COMUNS]
```
## Regras
Memorizar a estrutura, não o texto — discurso decorado soa artificial. Praticar em voz alta pelo menos 3 vezes.
