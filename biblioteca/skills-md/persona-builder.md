# Persona Builder — Criação de Persona de Público-Alvo

## Input necessário
```
PRODUTO/SERVIÇO: [o que é]
DADOS DO PÚBLICO: [o que já sabe sobre quem compra]
MERCADO: [Brasil / regional / global]
OBJETIVO: [para qual finalidade a persona será usada]
```

## Workflow
### ETAPA 1 — Briefing
Definir o objetivo central e o resultado esperado antes de começar a produzir.

### ETAPA 2 — Estrutura
Montar o esqueleto do documento, roteiro ou mensagem antes de preencher o conteúdo.

### ETAPA 3 — Desenvolvimento
Preencher cada parte com conteúdo real, específico e alinhado ao objetivo.

### ETAPA 4 — Revisão de Impacto
A peça cumpre seu objetivo? O leitor/espectador vai fazer o que precisa fazer?

### ETAPA 5 — Entrega
Formato final pronto para uso imediato, sem necessidade de edição adicional.

## Output
```
[PERSONA COMPLETA] — nome, perfil, dores, desejos, comportamento
[LINGUAGEM DA PERSONA] — como ela fala e o que a motiva
[IMPLICAÇÕES] — como cada aspecto da persona deve influenciar a comunicação
```
## Regras
Persona baseada em suposição é inútil — validar com dados reais de clientes existentes.
