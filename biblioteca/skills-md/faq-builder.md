# FAQ Builder — Perguntas Frequentes Estratégicas

## Input necessário
```
PRODUTO/SERVIÇO/EVENTO: [o que está sendo comunicado]
PÚBLICO: [quem vai receber o FAQ]
DÚVIDAS JÁ CONHECIDAS: [o que já perguntam com frequência]
CANAL: [onde o FAQ vai ser publicado]
```

## Workflow
### ETAPA 1 — Briefing
Definir o objetivo central e o resultado esperado antes de começar a produzir.

### ETAPA 2 — Estrutura
Montar o esqueleto do documento, roteiro ou mensagem antes de preencher o conteúdo.

### ETAPA 3 — Desenvolvimento
Preencher cada parte com conteúdo real, específico e alinhado ao objetivo.

### ETAPA 4 — Revisão de Impacto
A peça cumpre seu objetivo? O leitor/espectador vai fazer o que precisa fazer?

### ETAPA 5 — Entrega
Formato final pronto para uso imediato, sem necessidade de edição adicional.

## Output
```
[FAQ COMPLETO] — 10-20 perguntas e respostas
[ORGANIZAÇÃO] — agrupado por tema
[VERSÃO RESUMIDA] — top 5 dúvidas mais críticas
```
## Regras
FAQ deve antecipar objeções de venda — não é só informação, é ferramenta de conversão.
