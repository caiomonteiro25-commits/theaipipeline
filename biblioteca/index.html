MCPs

Plugins que dão superpoderes ao Claude. Ler arquivos do seu computador, mandar email, acessar Google Calendar, gerar imagens, transcrever áudio, controlar GitHub. Tudo conectado direto na conversa.

Pra quem e pra quê
  • Para criativos que cansaram de explicar o trabalho pro Claude todo dia. Instala uma vez, funciona pra sempre.
  • Para empreendedores que querem automatizar processos sem virar dev. Os MCPs fazem o Claude operar suas ferramentas.
  • Para alunos da mentoria que querem o sistema completo já montado, exatamente como uso na minha rotina.
  • Para quem produz música, eventos ou conteúdo e precisa de um time inteiro de IA, não de uma IA genérica.
Como instalar Skills

Skills · prompts que viram especialistas

01

Baixe o ZIP

Escolha a skill na biblioteca e clique em "Abrir no Drive" pra baixar o ZIP.

02

Abra o Claude Desktop

Versão com Computer Use ativado.

03

Arraste o ZIP

Envie o ZIP na conversa.

"Instale os skills do ZIP que enviei"
04

Claude instala

Ele descompacta e move pra pasta de skills do usuário.

/mnt/skills/user/[nome]/SKILL.md
05

Confirme

Peça a lista de skills instalados.

"Liste os skills instalados"
06

Use naturalmente

Converse normalmente. O Claude ativa o skill certo no contexto.

Como instalar MCPs

MCPs · plugins que dão superpoderes

01

Abra Claude Desktop

Vá em Settings → Developer → Edit Config (abre o claude_desktop_config.json).

02

Copie o snippet

Na biblioteca, clique no MCP → "Abrir no Drive" e pegue o JSON do servidor.

03

Cole no config

Adicione o servidor dentro de mcpServers do JSON.

"mcpServers": {"name": {"command": "npx", "args": [...]}}
04

Configure credenciais

Alguns MCPs pedem API key. Preencha nas variáveis de ambiente do JSON.

05

Reinicie o Claude

Feche e abra de novo pra carregar o servidor MCP.

06

Use as ferramentas

Confira o ícone de plug. Peça pro Claude usar a ferramenta nova.

"Liste os arquivos da pasta Documents"
Para múltiplos packs: baixe todos, coloque numa pasta, zipe tudo e faça 1 upload só pro Claude.
Skill do dia: use o skill-daily-generator todo dia. "Me sugira o skill do dia."
